# 🍳 Restaurant Pro Shop - Commercial Kitchen Equipment (Modern Demo)

A state-of-the-art, high-converting e-commerce & commercial foodservice equipment demo web application built for **Restaurant Pro Shop** (based on `https://restaurantproshop.elocalisdemo.top/`).

---

## 🚀 Quick Start (Kaise Run Karein)

### Option 1: One-Click Batch File (Sabse Aasan)
Simply double-click:
```
run-demo.bat
```
Yeh automatically local development server start karega aur aapke default browser me `http://localhost:5173` open kar dega.

### Option 2: Terminal / Command Prompt
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### Option 3: Production Build Preview
```bash
npm run preview
```
Production bundle is ready in the `dist/` folder.
